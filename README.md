# Vectoriseur GT7

Transforme une image (logo, dessin) en décalcomanies SVG pour l’éditeur de livrées de Gran Turismo 7 : fichiers de 15 360 octets maximum, découpés et parfaitement alignés. Gratuit, sans compte, l’image ne quitte pas ton appareil.

Ouvrir : https://gt7-vectoriseur.github.io/vectoriseur-gt7/

## Importer dans GT7

1. Télécharge le ZIP et décompresse-le. Les fichiers sont numérotés dans l’ordre d’empilement.
2. Sur gran-turismo.com, ouvre ton profil puis l’outil de téléversement de décalcomanies, et glisse les fichiers SVG.
3. Dans l’éditeur de livrées, ajoute la décalcomanie 1, place-la et règle sa taille.
4. Duplique ce calque et remplace sa décalcomanie par la 2 sans bouger ni redimensionner. Recommence pour les suivantes, chacune au-dessus de la précédente.
